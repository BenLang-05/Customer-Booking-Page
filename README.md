# Ease Ltd Database System

A database management system and web interface for a room booking company. 
The system allows users to view information relating to customers, bookings, employees, rooms, suppliers and branch operations.

## Features
Relational database design,
Login system,
Database record viewing,
Customer and booking management,
Room and branch management,
Supplier and order tracking

## Technologies Used
HTML,
CSS,
PHP,
SQL,
Oracle SQL*Plus

## Project Overview
This project was developed as part of a database systems module.
It involved creating a complete database solution, including conceptual and logical database design, SQL implementation, and a web-based interface for viewing stored records.

## Setup
This project requires a PHP environment and access to the database used by the application. 
Configuration details may need to be adjusted depending on the local setup.

## Notes
This repository is intended to showcase the project structure, database design, and source code. 
The original project was hosted on a university server environment and is included here for portfolio purposes.
